### 🚀 About Me

I am a **DevSecOps Engineer & Cloud Security Specialist** with a strong foundation in backend software engineering (**PHP / Laravel 11**). I specialize in designing **Zero-Trust Infrastructure**, building **automated SAST/DAST CI/CD security gates**, and writing **modular Infrastructure as Code (Terraform)** across AWS & Kubernetes environments.

- 🛡️ **Current Focus**: Automated Threat Remediation via AWS Lambda, K8s GitOps with ArgoCD & HashiCorp Vault.
- 🔒 **Security Standards**: OWASP Top 10, CIS Benchmarks, NIST Cybersecurity Framework, Container Hardening.
